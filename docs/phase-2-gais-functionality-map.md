# Phase 2 — GAIS Functionality Map

This document maps every catalogue/content-relevant capability found in the Google AI Studio (GAIS) prototype (`legacy-prototype/`) to its production MMKE representation, and notes what still needs building in Studio/Museum/integration phases. Nothing here is migrated data — this is a capability map, not a content migration (that's ADR §22, a later phase).

Legend: **✅ Represented** (schema exists now) · **🔜 Planned, not yet built** (schema doesn't cover it yet, future phase) · **❌ Not carried forward** (GAIS concept deliberately not reproduced, with reason).

## Summary

Most of what was genuinely *useful* about GAIS was its **product thinking**, not its code: the 11-step editorial wizard's shape, the notion of Programme-as-first-class, the participant/venue/educational fields on a recording draft, and the well-built (if orphaned) SEO generators. All of that is now represented by real, normalized, relationally-correct tables instead of a flat draft object or an unused TypeScript interface.

The things GAIS only ever *specified* as interfaces — recommendations, AI chat, semantic search, multi-provider media connectors, card design tokens — are deliberately **not** built into MMKE now. Building persistence for capabilities that were never implemented, never used, and never tested in GAIS would be inventing functionality, which Phase 2's instructions explicitly rule out. Where the ADR already anticipates a smaller, real version of one of these ideas (search, media providers), MMKE's structure is shaped so that future work is additive, not a rewrite.

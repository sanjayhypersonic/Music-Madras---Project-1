Music Madras — visual direction specimen

Palette specimens for the product-owner decision (Phase 6J-3A), generated from modules/design/visualDirections.ts by npm run design:specimen. They show roles (surfaces, text, links, buttons, badges, status colours, focus) — not product pages, and no catalogue data. The logo is the approved asset, unmodified. Direction A is what ships today; B, C and D are proposals whose exact values are open to adjustment once a direction is chosen. Headings use Georgia here only so this file is self-contained; the site uses Playfair Display and Inter.
